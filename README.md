# 📝 React Notes App

A simple, responsive notes application built with **React**, **Tailwind CSS**, and **Lucide React**. Create notes with a title and description, view them as cards, and delete them when they are no longer needed.

## ✨ Features

- **Create Notes** — Add a note with a title and description.
- **View Notes** — Display notes dynamically as cards.
- **Delete Notes** — Remove individual notes with a single click.
- **Responsive UI** — Adapt the layout to different screen sizes.
- **Clean Design** — Notebook-inspired cards with a minimal dark theme.

## 🛠️ Tech Stack

- **React** — Component-based UI and state management with Hooks.
- **JavaScript (ES6+)** — Application logic and event handling.
- **Tailwind CSS** — Responsive styling and utility classes.
- **Lucide React** — Icons.
- **Vite** — Development server and build tooling.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/) installed on your system.
- npm, which comes with Node.js.
- Git, if you want to clone the repository.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/wasimsaifi08/react-notes-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd react-notes-app
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually `http://localhost:5173`.

## 🧠 React Concepts Practiced

- `useState` for managing form values and notes.
- Controlled inputs using `value` and `onChange`.
- Form submission handling with `onSubmit`.
- Rendering lists dynamically with `map()`.
- Updating arrays immutably when adding and deleting notes.
- Responsive layouts using Tailwind CSS breakpoints.
